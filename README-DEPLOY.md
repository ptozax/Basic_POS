# วิธี Deploy LocalPOS ขึ้น Google Apps Script (เก็บข้อมูลบนคลาวด์ + ต้อง Login)

แอปนี้ทำงานได้ **2 โหมด** โดยใช้ไฟล์ `index.html` เดียวกัน:

| โหมด | เก็บข้อมูลที่ไหน | Login |
|------|----------------|-------|
| **เปิดไฟล์ `index.html` ตรง ๆ / เว็บทั่วไป** | `localStorage` ในเบราว์เซอร์ (เหมือนเดิม) | มีหน้า login แต่เป็นแค่การกันเข้าใช้เบื้องต้น — ไม่ใช่ความปลอดภัยจริง |
| **รันบน Google Apps Script (Web App)** | **Google Sheets (คลาวด์)** ✅ | ระบบ login จริง (รหัสผ่าน hash + token) ✅ |

โหมดคลาวด์คือสิ่งที่คุณต้องการ — ข้อมูลจะถูกเก็บบน Google Sheets เข้าถึงได้จากทุกเครื่อง และต้อง login ก่อนใช้งาน

---

## ขั้นตอนติดตั้ง (ทำครั้งเดียว ~10 นาที)

### 1. สร้าง Google Sheet
- ไปที่ https://sheets.google.com สร้างสเปรดชีตใหม่ 1 ไฟล์ (ปล่อยว่างไว้ ตั้งชื่ออะไรก็ได้ เช่น `POS Database`)

### 2. เปิด Apps Script
- ในสเปรดชีตนั้น เมนู **ส่วนขยาย (Extensions) → Apps Script**

### 3. วางโค้ดฝั่งเซิร์ฟเวอร์
- ในตัวแก้ไข Apps Script จะมีไฟล์ `Code.gs` อยู่แล้ว → ลบของเดิมทิ้ง แล้ว**คัดลอกเนื้อหาไฟล์ [`Code.gs`](Code.gs) ทั้งหมด**มาวาง

### 4. สร้างไฟล์ HTML ชื่อ `Index`
- กดปุ่ม **+** ข้าง ๆ "Files" → **HTML**
- ตั้งชื่อว่า **`Index`** (ตัว I ใหญ่ ไม่ต้องใส่ `.html` — Apps Script จะเป็น `Index.html` ให้เอง)
- ลบเนื้อหาตัวอย่างในไฟล์นั้นทิ้ง แล้ว**คัดลอกเนื้อหาไฟล์ [`index.html`](index.html) ทั้งหมด**มาวาง
- กด 💾 บันทึก (Ctrl+S)

> ⚠️ ชื่อไฟล์ต้องเป็น `Index` ให้ตรงกับที่ `doGet()` เรียกใช้ (`createHtmlOutputFromFile('Index')`)

### 5. รันฟังก์ชัน `setup()` หนึ่งครั้ง
- ที่แถบด้านบน เลือกฟังก์ชัน **`setup`** จาก dropdown → กด **Run (▶)**
- ครั้งแรกจะขอสิทธิ์ (Authorization) → กด **Review permissions** → เลือกบัญชี Google ของคุณ → Advanced → Go to (project) → **Allow**
- ฟังก์ชันนี้จะสร้างชีต `_store` (เก็บข้อมูล) กับ `_users` (บัญชีผู้ใช้) และสร้างผู้ดูแลระบบเริ่มต้น:
  - **username:** `admin`
  - **password:** `admin123`

### 6. Deploy เป็น Web App
- มุมขวาบน **Deploy → New deployment**
- ไอคอนเฟือง ⚙️ ข้าง "Select type" → เลือก **Web app**
- ตั้งค่า:
  - **Description:** อะไรก็ได้ เช่น `POS v1`
  - **Execute as:** **Me** (ตัวคุณเอง — เพื่อให้ทุกคนเขียนลง Sheet เดียวกันได้)
  - **Who has access:**
    - **Anyone** = เปิด URL ได้เลยไม่ต้องมี Google account (แนะนำสำหรับพนักงานหน้าร้าน เพราะยังต้อง login ในแอปอยู่ดี)
    - หรือ **Anyone with Google account** = ต้องล็อกอิน Google ก่อน แล้วค่อย login แอปอีกชั้น
- กด **Deploy** → คัดลอก **Web app URL** ที่ได้ (ลงท้ายด้วย `/exec`)

### 7. เปิดใช้งาน
- เปิด URL นั้นในเบราว์เซอร์ → เจอหน้า **login** → ใส่ `admin` / `admin123`
- **เปลี่ยนรหัสผ่านทันที** โดยกดปุ่ม 🔑 ที่มุมขวาบน

เสร็จแล้ว! ข้อมูลการขาย/สินค้า/ส่วนลด ทั้งหมดจะถูกเก็บบน Google Sheets โดยอัตโนมัติ

---

## การจัดการผู้ใช้ (เพิ่มพนักงาน)

มี 2 วิธี:

**วิธี A — แก้ในชีต `_users` ตรง ๆ:** ไม่แนะนำ เพราะต้องใส่ salt/hash เอง

**วิธี B — ใช้ฟังก์ชัน `addUser` (แนะนำ):** ใน Apps Script เพิ่มฟังก์ชันชั่วคราวแล้วรัน เช่น
```javascript
function addStaff() {
  // ต้อง login เป็น admin ก่อน เพื่อเอา token — หรือเรียก _createUser_ ตรง ๆ ก็ได้:
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  _createUser_(ss.getSheetByName('_users'), 'staff1', 'รหัสผ่านที่ตั้ง', 'ชื่อพนักงาน', 'staff');
}
```
รัน `addStaff()` หนึ่งครั้ง จากนั้นลบฟังก์ชันนี้ทิ้งได้

> `role` = `admin` (จัดการผู้ใช้ได้) หรือ `staff` (ใช้งานทั่วไป)

---

## อัปเดตโค้ดในอนาคต
เมื่อแก้ `index.html` หรือ `Code.gs` แล้ว ต้อง **Deploy → Manage deployments → (ดินสอ ✏️) → Version: New version → Deploy** เพื่อให้ URL เดิมได้โค้ดใหม่

## หมายเหตุด้านเทคนิค
- ข้อมูลเก็บแบบ key-value ในชีต `_store` โดย **แบ่ง chunk** ละ 45,000 ตัวอักษรต่อแถว เพื่อเลี่ยงลิมิต 50,000 ตัวอักษร/ช่องของ Google Sheets จึงรองรับข้อมูลขนาดใหญ่ได้
- การบันทึกจะ **รวม batch + หน่วง 0.7 วินาที** ก่อนส่งขึ้นเซิร์ฟเวอร์ (จุดสีมุมขวาบน: เหลือง=กำลังบันทึก, เขียว=บันทึกแล้ว, แดง=ผิดพลาด/จะลองใหม่)
- Token เซสชันอายุ 6 ชั่วโมง ต่ออายุอัตโนมัติเมื่อมีการใช้งาน เก็บใน CacheService (ฝั่งเซิร์ฟเวอร์) และจำ token ไว้ใน `localStorage` ฝั่งเบราว์เซอร์เพื่อไม่ต้อง login ใหม่ทุกครั้งที่รีเฟรช
- ฟีเจอร์ **สำรอง/นำเข้าข้อมูล (JSON)** เดิมยังใช้ได้ปกติทั้ง 2 โหมด — แนะนำให้สำรองไว้เป็นระยะ
